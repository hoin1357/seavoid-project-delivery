## 다른 컴퓨터에서 편집·실행

- **Unity 6000.2.10f1** 설치 후 Unity Hub에서 압축 해제된 `seavoid` 폴더를 추가합니다.
- `Assets/Seavoid/Scenes/DrownedDistrict.unity`를 열어 Play합니다. 확장 월드는 이미 씬에 저장되어 있습니다.
- Unity 없이 실행: `Builds/SEAVOID-Expanded/SEAVOID.exe`.
- 자세한 안내: 압축 안의 `OTHER-PC-README-KO.md`, `README.md`.
- 복원·압축 해제·Unity 첫 임포트를 위해 여유 공간 **20GB 이상 권장**.
